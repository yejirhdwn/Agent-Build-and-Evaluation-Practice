# 일반 이슈와 확인 포인트

## 대상·발송 단계

- 대상 수가 줄어든 경우 opt-out, 피로도, 중복 제거 등 각 제외 단계의 건수를 합산한다.
- 발송 요청은 있으나 전달 이력이 없으면 커밋 여부와 중계 대기 테이블 적재를 확인한다.
- 일부 상태만 남으면 캠페인 단위 시작·종료 줄과 상태별 이력을 대조한다.
- 처리 시간이 길면 정상 기준선의 elapsed와 tps를 같은 조건에서 비교한다.
- 발송일 검증 실패 가능성은 로그 시각의 날짜와 캠페인 발송일을 함께 비교한다.

## 결과·집계 단계

- 화면의 0 또는 빈 값은 집계 배치가 성공했는지만으로 정상이라고 판단하지 않는다.
- 집계 원천 테이블의 마지막 적재 시각과 결과 수신 배치의 실제 출력 테이블을 비교한다.
- 관련 없는 ERROR는 캠페인, 시각, 건수의 연결이 약하면 후순위로 둔다.
- 결과 파일 지연은 재시도 후 실제 적재 건수와 집계 실행 시각을 함께 확인한다.

## 자료 부족

- 종료 줄이 없으면 프로세스 종료, 서버 재기동, 스케줄러 실행 이력 등 필요한 자료를 요청한다.
- 롤백 줄이 없다는 사실만으로 롤백을 추측하지 않는다.
- 다른 캠페인의 정상 처리는 영향 범위를 좁히는 근거로 사용하되 시스템 전체 정상으로 일반화하지 않는다.
