# Agent Memory

## 프로젝트 개요

캠페인 발송·성과 집계 흐름의 원인을 목업 데이터로 추적하는 에이전트다. Codespace에서는 설계와 도구를 검증하고, 이후 VDI에서 실제 로그·DB·소스 조회 구현으로 교체한다.

## 작업 선호

- 보고서는 한국어로 작성한다.
- 표는 단계별 건수와 처리 시간 비교에 우선 사용한다.
- 요약은 3~5줄로 작성한다.

## 작업 힌트

- 입력 로그는 `/input/logs/` 아래에서 확인한다.
- DB·관계·소스·장애 이력은 조회 도구를 사용한다.
- 같은 파일을 반복해서 통째로 읽지 말고 검색 후 필요한 줄만 읽는다.
- 조회 결과의 파일명과 줄 번호를 보고서 근거로 남긴다.
